# Preserve the Infiniswap architecture during modernization

The modernization will retain Infiniswap's Memory Consumer, Memory Provider, and RDMA architecture while replacing obsolete kernel, build, configuration, and deployment interfaces and incorporating critical correctness fixes. Its goal is host-wide production operation in the controlled internal GPU/RDMA cluster, with performance against the existing local swap implementation as the primary value gate, plus packaging, observability, failure handling, upgrades, rollback, and explicit support and certification policies. Early block-device and Linux swap milestones remain narrower and make no GPU-workload performance claim; production readiness requires automated soak and fault testing, staged physical validation, a representative host-DRAM-heavy GPU workload, and a controlled maintenance-window deployment on `ty-gpu-02`. Alternative far-memory systems and experimental compression, erasure-coding, and GUI features remain out of scope.
