# Package and gate production releases

Production releases are delivered as versioned Debian packages for the DKMS Memory Consumer module, Memory Provider daemon and systemd unit, `infiniswapctl`, configuration schema, upgrade and rollback tooling, and module-signing integration. CLI and JSON status remain available while a machine-readable metrics endpoint and baseline alerts cover failure and capacity states. Release gates require automated fault tests, 24-hour VM soak on both supported Ubuntu kernels, 72-hour soak on each physically certified RDMA tuple, a seven-day non-critical canary using a frozen representative host-DRAM-heavy GPU workload, zero data miscompares or kernel oops/panics, no unexplained hung I/O, and a demonstrated rollback. Each Ubuntu 5.15 or 6.8 kernel ABI update must pass DKMS compilation, VM regression, and a short canary before production rollout; nodes remain pinned to the last validated ABI until then.
